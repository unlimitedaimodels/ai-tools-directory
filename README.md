# AI Tools Directory

A practical directory of AI tools with official links, intended use cases, and transparent notes. Verify pricing, privacy, and availability on each providers own website.

## Tools

1. **OpenAI** — General-purpose models, reasoning, agents, and developer APIs. [Official site](https://openai.com/)
2. **Claude** — Writing, analysis, coding, and long-context workflows. [Official site](https://www.anthropic.com/)
3. **Google Gemini** — Multimodal models and developer tooling. [Official site](https://ai.google.dev/)
4. **GitHub Copilot** — AI coding assistance inside developer workflows. [Official site](https://github.com/features/copilot)
5. **Perplexity** — Web-grounded research and answer discovery. [Official site](https://www.perplexity.ai/)
6. **Mistral AI** — Open and commercial models for developers and enterprises. [Official site](https://mistral.ai/)
7. **Cohere** — Enterprise language, retrieval, and search capabilities. [Official site](https://cohere.com/)
8. **Hugging Face** — Open models, datasets, demos, and community tooling. [Official site](https://huggingface.co/)
9. **Replicate** — Hosted model inference and deployment APIs. [Official site](https://replicate.com/)
10. **Together AI** — Hosted open-model inference and fine-tuning services. [Official site](https://www.together.ai/)

## How to evaluate a tool

Compare official documentation, model limitations, data-use policy, latency, pricing, rate limits, export options, and support before adopting a tool. Avoid copying credentials into untrusted websites.
